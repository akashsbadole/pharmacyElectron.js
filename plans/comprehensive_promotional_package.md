# GarmentPOS & PharmaMine Web - Comprehensive Promotional Package

## Product Overview

### Dual-Platform Retail Management Solution

**GarmentPOS & PharmaMine Web** is a comprehensive, dual-platform retail management system specifically designed for garment and retail businesses. This innovative solution combines the power of a desktop application with the accessibility of a web-based platform, providing businesses with unparalleled flexibility and functionality.

### Version Information
- **GarmentPOS Desktop**: Version 1.5.1
- **PharmaMine Web**: Version 1.0.0

## Technical Specifications

### System Requirements

#### Desktop Application (GarmentPOS)
- **Operating System**: Windows 10/11, macOS 10.14+, Linux
- **RAM**: 4GB minimum, 8GB recommended
- **Storage**: 500MB free space
- **Processor**: Intel i3 or AMD equivalent
- **Display**: 1024x768 minimum resolution

#### Web Application (PharmaMine Web)
- **Browser Support**: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **Internet Connection**: Required for web access
- **Database**: PostgreSQL 12+
- **Server**: Node.js 16+

### Technology Stack
- **Desktop**: Electron.js, JavaScript, HTML5, CSS3
- **Backend**: Node.js, Express.js, PostgreSQL
- **Frontend**: Vanilla JavaScript, Bootstrap 5, Chart.js
- **Database**: PostgreSQL, NeDB (for desktop)
- **Security**: JWT, bcrypt, Helmet.js, CORS protection

### Integration Capabilities
- **Payment Gateways**: Multiple payment processor support
- **Accounting Software**: Export capabilities for accounting integration
- **E-commerce**: API support for online store integration
- **Hardware**: Barcode scanners, receipt printers, cash drawers
