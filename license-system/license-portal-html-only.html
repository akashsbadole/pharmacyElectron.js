Setup Requirements:

  • Modify your Google Apps Script to return HTML responses (see guide below)

  • No CORS issues since forms submit directly to the script

📝 Google Apps Script Modification Guide

To make this HTML-only version work, you need to modify your Google Apps Script to handle form submissions and return HTML responses.

1. Add this function to your Google Apps Script:

/**
 * Handle form submissions and return HTML responses
 */
function doPost(e) {
  try {
    const path = e.parameter.path || '';
    const method = e.parameter.requestMethod || 'POST';
    
    // CORS headers for any potential AJAX calls
    const headers = {
      'Content-Type': 'text/html',
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'GET, POST, PUT, DELETE, OPTIONS',
      'Access-Control-Allow-Headers': 'Content-Type, Authorization'
    };

    let htmlResponse = '';
    
    if (path === '/generate') {
      const result = generateLicense(e);
      htmlResponse = generateLicenseHTML(result);
    } else if (path === '/validate') {
      const result = validateLicense(e);
      htmlResponse = validateLicenseHTML(result);
    } else if (path === '/status') {
      const result = getLicenseStatus(e);
      htmlResponse = statusLicenseHTML(result);
    } else {
      htmlResponse = errorHTML('Invalid endpoint');
    }

    return HtmlService.createHtmlOutput(htmlResponse).setSandboxMode(HtmlService.SandboxMode.IFRAME);

  } catch (error) {
    return HtmlService.createHtmlOutput(errorHTML(error.message));
  }
}

// HTML Response Generators
function generateLicenseHTML(data) {
  if (data.success) {
    return `
      
      
      
        License Generated
        
      
      
        
✓ License Generated Successfully!

        
Email: ${data.email}

        
License Key:

        
${data.license_key}

        
Subscription Type: ${data.subscription_type}

        
Expiry Date: ${new Date(data.expiry_date).toLocaleDateString()}

        
Status: ${data.status}

        

        
        
      
      
    `;
  } else {
    return errorHTML(data.error || 'Failed to generate license');
  }
}

function validateLicenseHTML(data) {
  if (data.success) {
    return `
      
      
      
        License Validated
        
      
      
        
✓ License is Valid!

        
Email: ${data.email}

        
License Key:

        
${data.license_key}

        
Status: ${data.status}

        
Expiry Date: ${new Date(data.expiry_date).toLocaleDateString()}

        ${data.activation_date ? `
Activation Date: ${new Date(data.activation_date).toLocaleDateString()}
` : ''}
        

        
      
      
    `;
  } else {
    return errorHTML(data.error || 'Invalid license');
  }
}

function statusLicenseHTML(data) {
  if (data.success && data.license) {
    const license = data.license;
    return `
      
      
      
        License Status
        
      
      
        
✓ License Found

        
Email: ${license.email}

        
License Key:

        
${license.license_key}

        
Subscription Type: ${license.subscription_type}

        
Status: ${license.status}

        
Expiry Date: ${new Date(license.expiry_date).toLocaleDateString()}

        ${license.activation_date ? `
Activation Date: ${new Date(license.activation_date).toLocaleDateString()}
` : ''}
        

        
      
      
    `;
  } else {
    return errorHTML(data.error || 'No license found for this email');
  }
}

function errorHTML(message) {
  return `
    
    
    
      Error
      
    
    
      
✗ Error

      
${message}

      

      
    
    
  `;
}

2. Deployment Steps:

  1. Open your Google Apps Script project
  2. Paste the above functions into your script
  3. Replace the existing doPost function or add these as new functions
  4. Deploy as Web App with "Anyone with the link" access
  5. Update the form action URLs in this HTML file with your new Web App URL

3. Benefits of HTML-Only Approach:

  • ✅ No CORS issues whatsoever
  • ✅ Works in any browser
  • ✅ No JavaScript required
  • ✅ Simple form submission
  • ✅ Direct response from Google Apps Script

🔧 Alternative Solutions

If you prefer not to modify your Google Apps Script:

Option 1: Use a Simple HTTP Server

Instead of opening HTML files directly from your file system, serve them using a simple HTTP server:

  • Python: python -m http.server 8000
  • Node.js: npx http-server
  • PHP: php -S localhost:8000

Option 2: Host on a Web Server

Upload your HTML files to any web hosting service (GitHub Pages, Netlify, etc.)

Option 3: Use the JSONP Version

Try the JSONP version which works with minimal Google Apps Script modifications
